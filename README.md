# E-commerce-product-page

A responsive e-commerce product page built with **React**, **Tailwind CSS**, and **Vite**.  
This project showcases product previews, a mobile-friendly image slider, a cart system, and a responsive header.

---

## Features

- Responsive **Header** with navigation links, avatar, and cart dropdown
- **Product Image Gallery** with clickable thumbnails
- **Mobile Image Slider** for product preview
- **Quantity Selector** and **Add to Cart** functionality
- **Cart Dropdown** showing selected items, quantity, price, and delete option
- Fully **responsive layout** for desktop and mobile
- Hover states for interactive elements
